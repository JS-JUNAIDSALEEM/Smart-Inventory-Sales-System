# Smart Inventory & Sales System

A Python-based command-line inventory and sales management system.

## Features

- View current inventory
- Sell products
- Restock existing products
- Add new products
- Delete products
- Apply discount coupons
- Track total earnings
- Save inventory data using JSON
- Reset shop database
- Input validation and error handling

## Technologies Used

- Python
- Object-Oriented Programming (OOP)
- JSON
- File Handling
- Exception Handling

## How to Run

1. Clone the repository
2. Open the project folder
3. Run:

```bash

python main.py
